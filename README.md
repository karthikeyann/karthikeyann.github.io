# karthikeyann.github.io

Personal website of Karthikeyan Natarajan: https://karthikeyann.github.io

Built with [al-folio](https://github.com/alshedivat/al-folio) (Jekyll, MIT license).
Every push to `master` builds and publishes the site through
`.github/workflows/deploy.yml` (Settings → Pages → Source: GitHub Actions).

- Content: `_pages/`, `_news/`, `_projects/`, `_bibliography/`, `_data/`
- Local preview: `docker compose up`, then open http://localhost:8080
- `old/`: archived copy of the previous hand-written site (served at `/old/`, not indexed)
